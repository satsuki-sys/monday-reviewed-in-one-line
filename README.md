A make.fun bounty entry for [Monday, Reviewed in One Line](https://make.fun/bounty/u-zeroxfive-monday-reviewed-in-one-line-e55de3c1).

The program writes the funniest one-line review of my own Monday — one line, no title, no explanation — to `/output/entry.txt`.

## Run

```sh
python3 main.py
```

It writes a single line of 1–200 characters to `/output/entry.txt`.
